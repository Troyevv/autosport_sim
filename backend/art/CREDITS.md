# Графика Autosport Sim

Студийные лица вымышленных персонажей, гоночные комбинезоны, поло персонала, куртки производителей и нейтральная одежда созданы для Autosport Sim с помощью OpenAI ImageGen. Авторские графические материалы проекта поставляются на условиях MIT. Исходная коллекция R3.2 подготовлена заранее с использованием MediaPipe Face Landmarker, Selfie Multiclass Segmenter и алгоритма посадки ткани R3.2. Положение головы, шеи, воротника и плеч измерено по каждому исходнику. В каталоге хранится одна внешность на ID, форма хранится отдельно и переиспользуется.

Для сторонних эмблем индивидуальные сведения об авторе, источнике, лицензии и преобразовании находятся в записях типа `logo` файла [catalog.json](catalog.json). Для растровых копий на условиях CC BY-SA действует лицензия исходного изображения. Товарные знаки принадлежат их владельцам. Если подтверждённой эмблемы нет, организация представлена названием и командными цветами.

[Исходный механизм портретов R3.2](https://github.com/Troyevv/esport_sim/blob/main/docs/PORTRAIT_FIT_R32.md) · [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

В [юниорской коллекции](junior/catalog.json) каждому вымышленному человеку соответствует отдельный студийный портрет ImageGen. Фон удалён хромакеем, у каждого изображения свой контур посадки ткани. Гардероб новых организаций использует тот же механизм смены формы. Авторские изображения и производные комплекты распространяются под MIT.

Шесть студийных мастер-шаблонов формы и кураторские границы воротников входят в проект на условиях MIT. Авторы изображений — Autosport Sim / OpenAI ImageGen. Каталог [wardrobe/catalog.json](wardrobe/catalog.json) содержит растровую ткань и отдельные маски цветовых зон. Авторские цветные оригиналы находятся в [scripts/data/wardrobe](../../scripts/data/wardrobe). Для каждого добавленного стороннего знака [logos/catalog.json](logos/catalog.json) указывает автора, исходный вектор, страницу бренда и условия использования. Права на товарные знаки принадлежат соответствующим организациям.

Мягкие маски головы и передних прядей получены из фотографий каталога. Для 365 фотографий юниоров восстановлена срезанная нижняя граница подбородка или шеи. Для двух исходников без глаз и верхней части головы (`generated-junior-driver-0155`, `generated-junior-driver-0283`) студийный портрет реконструирован с помощью OpenAI ImageGen по сохранившемуся фрагменту. Исходные ID сохранены. Контур волос с видимой прямой границей обрезки обработан по собственным прядям исходника. Производные материалы распространяются на тех же условиях, что и исходные студийные фотографии.

Для повторного аудита #52 подготовлены дополнительные студийные мастеры утраченных областей по сохранившимся изображениям конкретных вымышленных людей. Мастеры и производные изображения Autosport Sim / OpenAI ImageGen распространяются под MIT. Исходные данные, ограничения реконструкции и полноразмерные сравнения описаны в [отчёте о портретах](../../docs/issue-52/independent-audit/portraits/README.md).
