## Источники и воспроизведение

В исходниках исправлены подготовка изображения, регистрация головы и маски гардероба. Камера по-прежнему показывает голову, шею, плечи и верх груди. Полный комплект доступен в редакторе в режиме «Только форма». Игра читает готовые изображения из локального каталога. Реконструированные участки представляют утраченные детали по сохранившейся внешности. Проверить точное расположение отдельных волос, отсутствующих в архиве, невозможно.

Основные файлы обработки находятся в `scripts/portrait_processing.py`, `portrait_hair.py`, `portrait_edges.py`, `portrait_completion.py`, `portrait_repair.py` и `wardrobe_registration.py`. Мастеры реконструкции доступны в `scripts/data/portrait-restoration`. Идентификаторы лица и человека сохранены.

Для повторения открыть игру через Vite и запустить из корня проекта:

```sh
node frontend/scripts/portrait-proofs.mjs http://localhost:5173 CAREER_ID OUTPUT_DIR
```

Скрипт получает состав, назначения, экипировку и каталог изображений из работающего API. Для проверки конкретного листа после каталога вывода можно указать, например, `roster-082`. Полный отчёт по эмблемам содержит 144 отдельных результата, источники и ограничения распространения. [Реестр эмблем](../../wardrobe/logos.md)
