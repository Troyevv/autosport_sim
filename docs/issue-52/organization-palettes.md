# Фирменные палитры в игре

Все 98 команд и 46 производителей стартового мира имеют основной и дополнительный цвет. Для 128 организаций удалось сохранить обе краски из исходных каталогов. Для остальных 16 производителей, у которых был один общий серый цвет, в стартовый каталог внесли игровые палитры. Их RGB не сверялись с официальными брендбуками. Итого в данных 86 различных пар. В каталоге младших серий 67 организаций используют девять повторяющихся пар. Для одинаковых исходных данных расчёт даёт одинаковые цветовые токены. Любую такую палитру можно изменить отдельно. Название, эмблема, состав и рабочее место роли сохраняют собственную идентичность.

[Каталог формы 2025-v2](../../backend/data/2025-v2/kit-colors.json) · [Каталог цветов 2025-v4](../../backend/data/2025-v4/colors.json) · [Дополнение для производителей](../../backend/data/opening-2025/supplier-colors.json).

При создании карьеры за владельца или руководителя производителя можно выбрать два цвета и дополнительный акцент. Руководитель с контрольным пакетом может изменить их в профиле организации. Изменение сохраняется в карьере, применяется к навигации, заголовкам, панелям, кнопкам и договорным бланкам. Редактирование ливреи действует на одну заявку. Оба направления изоляции проверены через API, включая экспорт и импорт карьеры. Заводские расцветки всех 260 заявок, в том числе 128 машин младших серий, хранятся по заявкам. Содержимое заводского гаража до и после переноса совпало целиком. [Пресеты младших серий](../../backend/data/2025-v4/junior-garage-grid.csv). Цвета предупреждений, ошибок и подтверждений заданы отдельно и сохраняются при смене палитры.

## Контраст

Измерения выполнены на значениях токенов по формуле относительной яркости WCAG для sRGB. Для цветного текста на графите взята светлая из проверяемых тёмных подложек `#454548`, для границ — `#38383b`. Бумага, чернила, кнопка и надпись проверены в фактических парах каждой организации. В таблице приведены минимумы в стартовом каталоге.

| Что измерено | Критерий | Минимум среди 144 |
| --- | ---: | ---: |
| Фирменный текст на графите | 4,5∶1 | 4,60∶1 |
| Надпись на акцентной кнопке | 4,5∶1 | 9,15∶1 |
| Основная фирменная граница на графите | 3,0∶1 | 3,10∶1 |
| Фирменные чернила на бумаге | 4,5∶1 | 5,82∶1 |
| Линия на бумаге | 3,0∶1 | 3,10∶1 |

Автоматическая проверка охватывает также 36 комбинаций чёрного, белого, серого, чистого красного, зелёного и синего. Для каждой пары дополнительно проверяется равенство токенов при подстановке нового ID и названия. Пользовательский акцент проверен в сквозном сценарии создания, смены цветов, открытия договора и перезагрузки. [Тесты интерфейса](../../frontend/tests/brand.spec.ts) · [Тесты backend](../../backend/test_branding.py).

В Chromium дополнительно проверены 3 690 отображений текстовых элементов на однотонных подложках в штабах, профилях и документах шести карьер, на desktop и mobile. Использовались итоговые цвета браузера с учётом наложения фоновых слоёв. Все измеренные пары прошли порог 4,5∶1 для обычного и 3∶1 для крупного текста. В выборку не включались изображения, градиенты и элементы с групповой прозрачностью. Отдельный сценарий подтвердил, что кнопка следующего решения использует рассчитанные фон и надпись.
