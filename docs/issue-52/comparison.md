# Сверка с утверждённым интерактивным эталоном

В каждой паре слева запущен интерактивный эталон, справа — карьера на backend. В обоих кадрах одинаковы размеры окна. Цвета, компоновку и состояния проверяли отдельно от сумм, рейтингов и договоров конкретного сохранения. В реализованной версии оформление следует сохранённой палитре организации. Для команд, которым эталон назначал отдельную тему, это даёт другие оттенки.
