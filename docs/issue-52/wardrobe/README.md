Гардероб содержит шесть фотографических предметов. Жёсткая привязка к подбородку и расстоянию между глазами задаёт единый масштаб всего предмета. Воротник имеет заднюю и переднюю части, волосы над тканью берутся из исходного портрета. Цветовые зоны хранятся в отдельных масках. Эмблемы накладываются в координатах самого предмета с сохранением пропорций. Фотографии лиц остаются в существующем каталоге.

Редактор хранит в карьере выбор масок, распределение фирменных цветов и положение эмблемы по профессиям. Рекламная поверхность связана с карточкой действующего соглашения. Для персонального договора DAMS с HP проверены сохранение размещения и отсутствие знака у второго пилота. Восстановление стандартного кроя сохраняет обязательства по действующей рекламе.

В отдельной карьере один пилот перешёл из Williams в McLaren. Снимки воспроизводят последовательность игрового календаря. Прежняя форма видна 2 февраля после подписания, форма McLaren появляется 7 февраля, нейтральная серая одежда появляется 18 февраля после истечения срока. ID лица совпадает во всех трёх состояниях. В этой же карьере отдельно проверено увольнение действующего пилота.
