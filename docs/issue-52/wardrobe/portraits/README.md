## Исправленные дефекты

- Восстановлена нижняя граница 365 портретов юниоров. Раньше на этих исходниках могла исчезать часть нижней челюсти или шеи. Для двух лиц без верхней половины фотографии выполнена реконструкция (ячейки 395 и 431).
- У 983 исходников обработаны измеренные прямые границы обрезки волос. Передние пряди получили собственную мягкую маску поверх воротника.
- Фотографический шаблон одежды сохраняет геометрию, ширина плеч соотнесена с лицом, передний шов всех воротников отделён от внутренней стороны ткани.
- Одинаковый погрудный план используется в досье, списках, галерее и редакторе. Отдельная камера показывает целый предмет в режиме «Только форма».

## Воспроизведение

Запустите FastAPI и Vite с доступной карьерой. Из каталога frontend выполните `node scripts/portrait-proofs.mjs http://localhost:5173 <ID-карьеры> <каталог-результатов>`. Скрипт загружает реальные данные и тот же React-компонент, который используется игрой. Путь к установленному Chromium можно задать переменной CHROMIUM_PATH.
