# Карьера сезона 2025

В библиотеке выберите должность, чемпионат и организацию. Для повторяемой карьеры укажите seed от 0 до 4294967295. В верхней панели кнопка папки открывает экспорт и возврат в библиотеку. Импорт создаёт самостоятельную копию. Для просмотра исходных одиннадцати экранов оболочки выберите «Открыть деморежим».

## Стартовый мир

Срез составлен по заявкам первого этапа каждой серии сезона 2025, проверка источников 25 ноября 2026 года. Карьера начинается 1 февраля до презентаций и предсезонных тестов. Календарь воспроизводит запланированные уик-энды, без переноса реальных результатов, отмен и замен пилотов из будущего. 132 заявки участвуют в 64 этапах. Ещё четыре события относятся к презентациям и тестам.

| Чемпионат | Заявки | Этапы | Стартовый рынок шин |
|---|---:|---:|---|
| F1 | 20 | 24 | Pirelli |
| F2 | 22 | 14 | Pirelli |
| F3 | 30 | 10 | Pirelli |
| DTM, класс GT3 | 24 | 8 | Pirelli |
| WEC | 36 | 8 | Michelin в Hypercar, Goodyear в LMGT3 |

Один ID человека может участвовать в нескольких программах и занимать несколько должностей. В WEC Камуи Кобаяши совмещает руководство Toyota и пилотирование машины №7. Для неизвестных назначений сохраняется должность. Численность коллективов, ФОТ, навыки, бюджеты и цвета формы — игровые оценки. Пустое поле поставщика означает отсутствие подтверждённой записи. Продукты и должности описаны в каталоге, назначения и счета относятся к конкретному сохранению. [Первичные источники и дата среза](../../backend/data/2025-v1/sources.json)

## Регламенты и следующие этапы

Спортивные правила привязаны к чемпионату и сезону. У машины есть отдельные ссылки на техническую редакцию, поколение и концепцию. Начальные конфигурации входят в контрольную точку. У F1 подготовлены цели текущего и следующего сезона. Обе цели ссылаются на бюджет одной организации. Дата работы определяет общий период ATR. До конца периода 3 применяется итоговая классификация 2024 года. Для последующих периодов нужен результат игрового чемпионата, поэтому до появления классификации в игре показывается неопределённый коэффициент. В интерфейсе потолок F1 указан в USD до индексации и поправки на число этапов. Денежный журнал ведётся в евроцентах. Правила FIA финансового учёта и ATR относятся к командам F1. [Версии правил, периоды и исходные документы](../../backend/data/2025-v1/engineering.json)

У шинного регламента есть сезон, класс, режим рынка и допущенные поставщики. В открытом режиме необходима омологация изделия. Технический консультант работает на производителя и может получать ограниченные каналы наблюдения по назначению в клиентскую команду. Границы доступа включают договор, организацию, срок, тип продукта, сессию и идентификаторы техники. Реальные измерения появятся вместе с общим движком сессий. Резервирование ресурсов, R&D, обслуживание контрактов и гоночная симуляция распределены по следующим задачам. [Распределение работ](../ROADMAP.md)

## SQLite и перенос сохранений

Файл по умолчанию находится в `.autosport/world.sqlite3`. Переменная `AUTOSPORT_DATA_DIR` задаёт отдельный каталог. Схема обновляется последовательными транзакционными миграциями `PRAGMA user_version`. Версия 1 содержит снимки карьер, проводки и квитанции команд. Версия 2 добавляет локальные изображения. Пользовательские файлы исключены из Git.

Один запрос продвижения переводит мир к следующей дате события. Обязательные брифинги активных программ сохраняются до подтверждения. Операции изменения выполняются внутри `BEGIN IMMEDIATE`. Ревизия и ключ команды проверяются под блокировкой, месячная выплата уникальна для карьеры, организации и периода. Закрытие и повторный запуск используют сохранённую контрольную точку. При переносе проверяются версия правил, SHA-256 и согласованность состояния с последовательностью команд, включая назначения, кошелёк, проводки и RNG. Журнал команд используется для проверки импорта. Обычная загрузка читает снимок напрямую.

## Приватный ZIP с изображениями

Из корня репозитория запустите сборщик. Путь в примере сохраняет ZIP рядом с папкой проекта.

```sh
uv run --locked --extra media-builder python -m scripts.build_media ../autosport-2025.zip
```

В библиотеке карьер нажмите **Подключить ZIP** и выберите полученный файл. После импорта изображения загружаются с локального API. Для назначения лица новому игроку подключите пакет перед созданием карьеры. Назначенный ID переживает загрузку и переезд сохранения в другую установку. Уже известному реальному человеку соответствует только его собственный портрет.

Сборщик обходит всех уникальных людей стартовой базы. Результаты поиска на официальных сайтах, ограничения источника и статистика фактически упакованных изображений записываются в соседний файл `autosport-2025-report.json`. Реестр `backend/data/official-portraits.json` хранит только индивидуальные студийные оригиналы после проверки личности, условий обработки, ракурса, полного контура головы, шеи, обоих плеч, освещения и отсутствия головного убора и солнцезащитных очков. Проверка привязана к SHA-256 исходника. Ссылки из исследовательского списка не участвуют в автоматическом отборе. Обновление медиатеки убирает ранее импортированные реальные портреты без студийной проверки. Силуэт сохраняет роль и форму организации. Студийные фотографии для процедурных людей созданы специально для игры.

Обработчик и посадка ткани перенесены из [esport_sim R3.2](https://github.com/Troyevv/esport_sim/tree/7a8bfba03e8aa4226333d7d9be6460792361bb51). Локальные модели измеряют ракурс и выделяют человека. Затем сборщик отдельно восстанавливает видимую кожу шеи из того же снимка и измеряет плечи и край воротника. Для одного студийного снимка две точки на плечах уточнены вручную по оригиналу, поправка привязана к SHA-256 исходника. При смене одежды браузер укладывает ткань по индивидуальному контуру. Профиль и примерочная используют персональное кадрирование всей фигуры. Гоночные комбинезоны, поло персонала, куртки производителей и нейтральные джемперы созданы для автоспорта.

Версия пакета 1 содержит тип, ID, относительный путь, SHA-256, автора, источник, условия и описание обработки каждого файла. Допускаются PNG, WebP и JPEG, до 4 МиБ на файл, до 64 МиБ на архив и его распакованное содержимое. Слои прежнего формата используют RGBA 256×320. Для R3.2 слой внешности имеет размер 480×560, кадр и 27 пар координат тела. Ткань хранится в исходном разрешении со своей калибровкой воротника и плеч. Категории `head`, `generated-head`, `uniform`, `logo`, `sponsor-strip` и `car` разделены. Данные изображений записываются только после проверки всего архива. Товарные знаки принадлежат правообладателям. ZIP предназначен для ручного локального подключения.

## Проверка через интерфейс

В Chromium проверены создание карьеры McLaren, обязательный брифинг презентации MCL39, переход к календарю WEC и перенос сохранения через JSON. В двух отдельных карьерах проверены состав ABT Sportsline в DTM и клиентские заявки Goodyear в WEC. Шинный регламент WEC показывает своего поставщика для каждого класса.

Проверка с контрольным пакетом из 35 изображений включала повторную установку, отказ при повреждённом ZIP, досье игрока с назначенным лицом и служебной формой, а также силуэт Лэнса Стролла при отсутствии его фотографии. После остановки и повторного запуска процесса API с той же SQLite побайтово совпали экспорт сохранения, ответ штаба, каталог и индекс медиатеки.
