## Проверенные сценарии

Девять браузерных сценариев выполнены в каждом из двух профилей. Использовался локальный Chromium 156.0.8078.79, которым управлял Playwright. В каждом разделе проверялась ширина документа. На телефоне дополнительно проверялась доступность конца содержимого над нижней навигацией.

| Область | Наблюдаемый результат |
|---|---|
| Навигация | Открыты все 11 разделов через меню. Смена роли ведёт на нужное рабочее место. Переход производителя по адресу кабинета владельца возвращает его в производство. |
| Оболочка | Клик по фону поверх «Продолжить» закрывает меню и сохраняет дату. Фокус возвращается на кнопку открытия. Поиск по Ctrl+K показывает пустую выборку и открывает досье. Escape закрывает диалог, Tab удерживает фокус внутри. Прочитанное сообщение меняет статус. |
| Люди и рынок | Пустой список сброшен фильтром. У двух пилотов сверены сопоставимые навыки. Открыты профиль и история технического директора. Отобран кандидат GT. Нулевая зарплата блокирует отправку. Отмена сохраняет число переговоров, подтверждение добавляет условия кандидата. Запрос поставщику виден в тех же переговорах. |
| Работа менеджера | Подтверждение проекта уменьшило резерв с €38,4 до €36,6 млн и дало одну строку журнала. После двух дней стало доступно обновление днища. В календаре выбран этап Endurance. В гараже проверены ограничение редактора и осмотр компонента. |
| Роли | Форма владельца разрешила сохранить доли при сумме 100%. Из карточки программы открыт зачёт экипажей. У производителя приём заказа поднял загрузку с 76% до 84%, завершение вернуло её к 76%. |
| Гоночный центр | На карте и в тайминге выбран Вебер, переключён расчёт отображаемого отрыва. Проверены воспроизведение на 16×, пауза, темп и запись радио, выбор Hard и отмена плана остановки. Возврат в раздел открывает показ на паузе. У производителя команды пилотам скрыты. |
| Запуск и сброс | При ответе 503 показано сообщение о связи с API. Повтор вернул интерфейс. Сброс и обновление страницы восстановили исходную дату. |
| Гараж трёх программ | Переключение дисциплины меняет паспорт и декодируемое изображение автомобиля. Полноразмерный просмотр доступен в диалоге для каждой из трёх машин. |
| Другие формы | Проверены предел назначений инженеров, аванс партнёра, выгрузка CSV, инвестиция в объект, изменение цели, смен, цены и спецификации изделия. |

Для повторной съёмки задайте переменную окружения `EVIDENCE_DIR` с путём к каталогу перед `npm run smoke`. Playwright сохранит PNG для всех разделов.

Карьерное сохранение, правила гонок и редактор ливреи относятся к следующим задачам. Мобильные проверки проведены в эмуляции Chromium. Windows и реальный телефон в этом прогоне не использовались.
