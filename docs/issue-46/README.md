# Исследовательский центр и архив организации

В карьере менеджера откройте **Исследования**. Выберите направление, источник и приоритет. До подтверждения видны ответственный специалист, трудоёмкость и расход. В центре можно арендовать слот на неделю. Другие сроки, собственные объекты и бронирования доступны в «Инфраструктуре».

| Сценарий | Компьютер, 1440×900 | Телефон, 390×844 |
| --- | --- | --- |
| Две работы McLaren конкурируют за один слот. Исследование охлаждения по открытым сведениям о RB21 получило высокий приоритет. | [Очередь](desktop-queue.png) | [Очередь](mobile-queue.png) |
| Штаб оценивает применимость заключения к поколению F1 2026. Архив хранит первоначальный вывод, источник и вклад участников. | [Архив](desktop-memory.png) | [Архив](mobile-memory.png) |

Снимки получены в Chromium из работающей карьеры с FastAPI и SQLite. Сценарий Playwright проверяет повтор загрузки после ошибки, отмену и возврат фокуса, аренду, оплату двух поручений, изменение очереди, календарный прогресс, разбор отчёта с коллегой и сохранение после перезагрузки.

Доменные проверки находятся в `backend/test_research.py`. Они охватывают конкуренцию за время специалиста и центра, учёт расходов, закрытость отчётов NPC, работу с открытыми источниками, неопределённость, переносимость, увольнение автора, повтор команд и рабочего дня, откат при сбое статистики и перенос карьеры из схемы 20.
