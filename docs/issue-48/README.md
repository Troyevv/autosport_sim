# Производственный центр

В карьере откройте **Производственный центр → Новый заказ**. Выберите заявку, редакцию, исполнителя и количество. Для работы внутри организации нужен свободный слот производственного комплекса. В центре можно арендовать один слот на семь дней, в разделе инфраструктуры — выбрать другой срок или число слотов. Для приёмки отдельно требуется центр контроля качества.

## От заказа до установки

1. Новый заказ может повторять любой доступный команде выпущенный чертёж. В форме видны цена, трудоёмкость, договорные ограничения и доступный бюджет. Стандартные и омологированные узлы заказываются у разрешённого изготовителя. Подряд использует оплаченный внешний слот или покупает одну смену в пределах мандата.
2. Смена использует четыре часа руководителя работ и квалифицированное время подразделения. Оборудование, усталость, нагрузка и квалификация влияют на выработку. Срок в очереди — оценка по фактической выработке партии, до первой смены используется ориентир 24 нормо-часа. Приостановленный допуск, занятый специалист или отсутствие слота оставляют заказ в очереди с причиной.
3. Срочная партия требует примерно на треть меньше нормо-часов. Игровая надбавка составляет 50% базовой цены. Подряд добавляет 25% к базе и оплачивается по тарифу инфраструктуры. Семидневная аренда списывается один раз. Себестоимость изготовленных экземпляров включает долю фактически занятой арендной мощности.
4. Экземпляры поступают на контроль с серийными номерами. Риск рассчитывается по качеству отработанных смен с учётом состояния оборудования, квалификации, загрузки и срочности. По seed и ID партии определяется общий брак, по seed и ID экземпляра — индивидуальный. Инспектор может выявить дефект, пропустить его либо назначить дополнительную проверку. Подтверждённый брак партии блокирует оставшиеся затронутые экземпляры. Истинные признаки доступны домену физики, в интерфейсе отображаются подписанные результаты.
5. Допущенная деталь появляется на складе. В карточке доступны ресурс, пробег, износ, версия, история, разрешённые действия и распределение по машинам. Ремонт устраняет обнаруженную неисправность с последующим контролем. Пробег и накопленный износ сохраняются. Списание окончательно исключает экземпляр из доступного запаса.
6. Отдел рассчитывает резерв по числу совместимых автомобилей, включая общую машину экипажа WEC. В потребность входят недостающий запас и замены изношенных деталей, из неё вычитаются пригодный складской запас и заказанные экземпляры. Физически доступные детали распределяются по договорным статусам #44. Для временного дефицита с оплаченной следующей партией фиксируются план и ориентир устранения.

## Проверка в браузере

Сценарий `frontend/tests/production.spec.ts` открывает карьеру McLaren, оформляет срочную партию, проверяет ограничение количества, отсутствие мощности, аренду обоих участков и смену приоритета. После изготовления он проверяет два экземпляра в ОТК, находит принятый серийный номер на складе, устанавливает его и открывает тот же экземпляр после перезагрузки. Для повторной записи снимков укажите каталог в `PRODUCTION_EVIDENCE`.
