# Первое задание Codex

Использовать репозиторий `Troyevv/autosport_sim` и issue [#2](https://github.com/Troyevv/autosport_sim/issues/2).

Текст задания:

> Реализуй issue #2 полностью в отдельной ветке и подготовь PR. Сначала прочитай AGENTS.md, docs/PRODUCT.md, docs/ARCHITECTURE.md, docs/ROADMAP.md и reference/ui-v1/README.md. Запусти локальный эталон и используй его для всего интерфейса. Сохрани законченный тёмный дизайн, все 11 разделов и мобильную адаптацию; не делай упрощённый MVP UI. Учти последнее решение: гараж первой версии — качественный боковой 2D-вид, старое процедурное 3D переносить нельзя. Соблюдай границы этой issue: демонстрационный адаптер допустим только как явно обозначенный режим; весь эпик и игровую симуляцию в этот PR не включай. Проверь запуск, сборку и затронутые сценарии в браузере на desktop/mobile, приложи скриншоты. В результате перечисли выполненные критерии, фактические проверки и ограничения.

После включения результата первой задачи выполнить [#3](https://github.com/Troyevv/autosport_sim/issues/3). Дальнейший порядок — [ROADMAP.md](ROADMAP.md).
