# Персональные инженерные назначения

## Аудит стартового мира 2025

Проверен `main` после слияния #66, коммит `bad482d`. Из 447 заявок 260 уже имели своего гоночного инженера. Среди них все экипажи WEC. У 187 заявок OK и OK-Junior были личные механики. Для этих заявок добавлены отдельные должности гоночных инженеров.

Договоры стартового мира образуют 377 пар между производителем и клиентской командой. У 46 поставщиков было по одной штатной должности технического консультанта. Короткие назначения по отдельным продуктам покрывали только часть клиентов. Исходные трудовые договоры и периоды поддержки сохранены. Дополнительно введена 331 клиентская должность. Поставка нескольких узлов или обслуживание нескольких заявок одной команды требует одного консультанта от данного производителя.

## Кадры, поставки и данные

- Штатное место, зарплата, переход и освобождение должности проходят через кадровую книгу. Временное назначение использует оплачиваемый резерв. Оклад начисляется один раз. После замещения восстанавливаются полномочия действующего на эту дату сотрудника.
- При подписании поставки проверяются периоды занятости сотрудников. Если свободного консультанта нет, договор и финансовые обязательства не регистрируются. Найм сотрудника позволяет расширить портфель клиентов. Расторжение одного договора сохраняет обслуживание команды по оставшимся действующим поставкам.
- Гоночный инженер работает с фактическим составом заявки. Брифинг фиксирует состав, обратную связь и технические обращения. Решения учитывают навыки, доверие и совместный стаж пары. В кабинете производителя запрос сохраняет имя консультанта, а диагностический разбор учитывает разрешённые наблюдения по конкретному экземпляру.
- Права доступа проверяются отдельно по клиенту, договору, заявке, изделию, периоду и каналу. Новое назначение не открывает наблюдения сотрудника, работавшего до замены.
- Новые кадровые данные вводятся на игровой дате сохранения. Восстановление журнала воспроизводит прежние команды до этой точки. Стартовые специалисты имеют постоянные профили и лица. [Источники изображений](../../backend/art/CREDITS.md)
