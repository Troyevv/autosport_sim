# Инженерный штаб

В карьере менеджера откройте **Инженерный штаб → Совещания**. В карточке видны машина, наблюдение, гипотезы специалистов и заключение главного инженера. Раскройте источники и сравните стоимость, оборудование и риски вариантов. Через «Рассмотреть вариант» можно утвердить работу, поручить выбор специалисту, запросить исследование, отложить решение или отклонить его.

**Исполнение** показывает фактическое поручение в технической подсистеме, выработку, препятствия и итог. Менеджер может изменить приоритет открытой работы или прекратить производственный заказ. В **Протоколах** сохраняются основания, позиции и решения. Для изменения режима откройте **Полномочия**.

Снимки делает Playwright при запуске сценария `frontend/tests/council.spec.ts` с заданным каталогом `COUNCIL_EVIDENCE`. Сценарий создаёт карьеру McLaren, рассматривает разногласие по днищу, запрашивает исследование, вмешивается в его приоритет, открывает протокол и проверяет сохранение частичного делегирования после перезагрузки.

Тесты `backend/test_council.py` проверяют решение по парным измерениям, ошибочный прогноз, разные полномочия, реальные затраты и очереди, работу NPC, откат транзакции, права на наблюдения, миграцию и воспроизведение архива. Синтетические показания используются только в тестовых сценариях. Источником игровых трассовых измерений станет гоночный движок.
