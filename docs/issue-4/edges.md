# Проверка краёв на двух подложках

Каждый лист снят из собранной стартовой модели в Chromium. Слева направо показаны кокпит, верхний воздухозаборник или крыша, заднее антикрыло и переднее колесо. Верхние две строки используют тёмный фон, нижние — светлый. В строке 100% один пиксель исходника занимает один пиксель файла. В строке 200% каждый пиксель удвоен без интерполяции. Чтобы увидеть это соотношение, откройте файл в исходном размере.
