# Программа сезона

Рабочее место открывается из меню действующей карьеры команды. В браузерном сценарии менеджер McLaren рассматривает предложение для 2026 года. Утверждение создаёт исследование в календаре следующей машины. После перераспределения ресурсов текущая программа показывает остановку работ. После перезагрузки видны принятое решение и его автор.

Сценарии домена в `backend/test_programme.py` проверяют конкуренцию поколений за один слот и одного специалиста, остановку и возобновление, расходы и атомарный откат, перенос знаний, смену периода ATR, выпуск и производство будущей спецификации, частичную готовность, допуск и заморозку, управление сроком, работу делегирования и NPC, миграцию и перенос. Браузерный тест расположен в `frontend/tests/programme.spec.ts`. На этих экранах отображаются документы, расчёты КБ и инженерные испытания. Гоночные наблюдения поступают только от авторизованного источника.
