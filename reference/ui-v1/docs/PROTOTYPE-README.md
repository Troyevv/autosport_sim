# APEX — Motorsport Manager · интерфейс 1.0

Интерактивный визуальный эталон всей игры для Александра и последующей разработки в Codex.

Рабочее название **APEX**, вымышленная группа **VANTA** и сезон **2028** используются для демонстрации. Они не фиксируют окончательное название игры или состав чемпионатов.

## Запуск

Проект работает без сборки, сервера API, npm install и внешних CDN. Все необходимые изображения, шрифты, иконки и 3D-библиотеки находятся в `dist`.

Из корня проекта:

```bash
python -m http.server 8080 --directory dist
```

На Windows можно использовать `py -m http.server 8080 --directory dist`. Откройте `http://localhost:8080` в браузере. HTTP-сервер нужен для ES-модулей; открытие `index.html` через `file://` не поддерживается.

## Что открыть сначала

1. **Штаб** — общая композиция интерфейса, показатели, входящие и переходы.
2. **Пилоты и персонал** — досье, характеристики, трейты, сравнение и контракты.
3. **Гараж** — вращение автомобиля, смена ливреи, покрытий, логотипов и освещения.
4. **Гоночный центр** — запустить гонку, выбрать скорость, темп и комплект для пит-стопа.
5. Через название VANTA в меню переключить роль на **Владельца** или **Производителя**.

На телефоне полное меню открывается кнопкой «Ещё» или верхней кнопкой меню.

Изменения сохраняются в localStorage этого браузера. В настройках есть «Сбросить демо» с подтверждением.

## Задача для Codex

Использовать работающий прототип и `docs/REFERENCE.md` как согласованный эталон интерфейса. При подключении игровой логики сохранять композицию, визуальную иерархию, основные размеры, навигацию, мобильную раскладку и поведение элементов. Не заменять экраны упрощёнными таблицами, пустыми карточками или кнопками-заглушками.

Этот проект определяет **интерфейс и наблюдаемое поведение**, а не архитектуру будущего полноценного игрового движка. Нужную архитектуру симуляции, сохранений и серверных данных проектировать отдельно. Не переносить идентификаторы размещения прототипа в новый игровой репозиторий.

## Границы версии

- Это интерактивный макет, а не завершённая игра и не симуляция бесконечной карьеры.
- Показаны формулы, GT и выносливость. Гоночный экран использует один демонстрационный сценарий; результаты не меняют таблицы чемпионата.
- Рейтинги, деньги, регламенты, люди и результаты демонстрационные.
- Контрактные предложения сохраняются в списке переговоров; автономных переговоров NPC здесь нет.
- Кнопка «Продолжить» меняет дату и прогресс проектов. Полноценная синхронная симуляция календаря не реализована.
- Общий демонстрационный резерв VANTA связывает финансовые действия разных ролей. Раздельный бухгалтерский учёт организаций — задача игровой реализации.
- 3D-модели процедурные и условные. Для финальной игры их можно заменить подготовленными GLB-моделями с качественной UV-развёрткой, сохранив устройство гаража и редактора.
- При отсутствии WebGL используется программное отображение той же геометрии; материалы и освещение проще, чем в WebGL.
- Иллюстрация в штабе задаёт художественное направление; она не является скриншотом 3D-движка и не перекрашивается редактором ливреи.
- Прогнозы, некоторые сводные KPI и история результатов — фиксированные демонстрационные данные.

Дальнейшие изменения должны уточнять эталон по обратной связи пользователя. Название, логотипы и демонстрационные данные можно заменить без изменения основной композиции.
