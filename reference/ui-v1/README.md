# UI reference v1 — исторический интерактивный макет

## Действующее решение пользователя: гараж v1 использует 2D

Пользователь предварительно принял общее визуальное направление **всего интерфейса**, но отклонил мультяшную процедурную 3D-модель автомобиля.

**Для первой версии продукта требуется качественный фотореалистичный вид машины строго сбоку с редактируемой ливреей.** Цвета кузова, декоративные слои, номер и логотипы спонсоров должны изменяться без повторной генерации изображения. Сохранить тёмный гараж и верхние прожекторы. Блики, тени и материалы исходного изображения должны сохраняться при перекрашивании.

Текущая папка содержит зафиксированный исходный макет с историческим 3D-гаражом. **Не переносить его процедурные модели, орбитальную камеру и обязательность WebGL в продукт.** Соответствующие пункты архивных документов в `docs/` описывают предыдущую итерацию и не отменяют более позднее решение о 2D.

Данные ливреи хранить отдельно от визуализатора: цвета, слои/паттерны, номер и нормализованные позиции спонсоров не должны зависеть от Canvas-объектов, DOM или геометрии старого прототипа. Будущая поддержка 3D потребует собственного преобразования координат; она не входит в стартовую версию.

## Зачем сохранён этот макет

Это локально доступный визуальный и интерактивный референс для Codex: навигация, композиция 11 экранов, типографика, тёмная палитра, плотность информации, досье, трейты, формы, таблицы и мобильная адаптация.

Макет не является игровым движком и не задаёт архитектуру продукта. Его демонстрационные суммы, результаты, localStorage и упрощённая симуляция гонки не заменяют игровую модель и полноценные сохранения.

Использовать актуальные требования в корневых `AGENTS.md`, продуктовых документах и GitHub issues. Эта папка сохраняет исходный визуальный пример; изменения продукта следует делать в его собственном приложении. Папка не зависит от приватной ссылки ChatGPT Sites и не содержит идентификаторов размещения.

## Запуск

Из корня репозитория:

```bash
python -m http.server 8080 --directory reference/ui-v1/dist
```

На Windows можно использовать `py -m http.server 8080 --directory reference/ui-v1/dist`.

Открыть `http://localhost:8080` в браузере. Для ES-модулей нужен HTTP-сервер; прямое открытие `index.html` через `file://` не поддерживается. Установка npm-пакетов не требуется: изображения, шрифты, иконки и библиотеки находятся рядом с приложением.

## Структура

- `dist/` — самостоятельный работающий макет.
- `docs/PROTOTYPE-README.md` — исходный README, сохранённый как историческое описание.
- `docs/REFERENCE.md` — описание предыдущей итерации интерфейса; требования 3D перекрыты решением выше.
- `docs/ACCEPTANCE.md` — исходные сценарии приёмки макета.
- `docs/VALIDATION.md` — фактически проведённая проверка исходной итерации.
- `docs/ASSETS.md` — происхождение изображений и зависимостей.
